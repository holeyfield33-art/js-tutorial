# JavaScript Tutorial

**A clean, progressive, beginner-to-intermediate JavaScript tutorial series (v1).**  
No fluff. Real explanations. Working code. Exercises that actually teach.

> **Status:** v1 Blueprint — actively being written  
> **Goal:** Take someone from zero to confident modern JavaScript (ES6+ / ES2020+ focus)

A progressive, no-fluff JavaScript course that teaches modern practice from the first lesson. Clear mental models, working examples, and exercises that force understanding—not just syntax. Built for people who want to actually write JavaScript, not just read about it.

---

## Vision

This repository teaches JavaScript the way it is actually used today:

- Clear mental models before syntax
- Modern practices (ES6+) preferred over legacy habits
- Small, focused lessons with real examples
- Exercises that force understanding, not just copy-paste
- Progressive projects that grow with the student
- Browser + Node.js paths where relevant

---

## How to Use This Tutorial

1. Start with **Lesson 00** (setup) even if you already have a runtime.
2. Read each lesson carefully — don’t skip the “Why” sections.
3. Type the examples yourself. Don’t just read them.
4. Complete the exercises before moving on.
5. When you finish a section, do the mini-project.

**Recommended tools:**
- Runtime: Node.js (LTS) or a modern browser (Chrome / Firefox / Edge)
- Editor: VS Code + JavaScript/TypeScript extensions
- Optional later: npm, Vite, or a simple bundler
